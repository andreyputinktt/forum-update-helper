# ForumUpdateHelperBot

Telegram-бот для подготовки к форуму по форматам YPO и X-Competence.

## Что делает

- Онбордит участника: бизнес-клуб, Фамилия Имя, форум-группа, методика
  апдейта (`Классическая (YPO)` или `С личной стратегией (X-Competence)`),
  username получателя отчётов, настройка хранения файлов, дата следующего
  форума. Все шаги, кроме выбора методики, можно пропустить; бот подставит
  безопасные дефолты. При повторном `/start` бот заново проходит эти вопросы и
  предлагает подтвердить уже сохранённые значения кнопкой. Получатель отчётов
  должен хотя бы раз запустить бота.
- Личный кабинет: все поля профиля можно посмотреть и изменить в Telegram,
  а удаление данных находится внутри личного кабинета.
- За 3 дня до форума начинает подготовку апдейта и задаёт первый вопрос.
- Ведёт по вопросам выбранной методики: классический Forum Update / YPO или
  формат с личной стратегией X-Competence.
- На один вопрос можно отправить несколько сообщений; к следующему вопросу бот
  переходит только после кнопки ➡️. Пустые вопросы можно пропускать.
- При старте подготовки предлагает новый апдейт или редактирование предыдущего.
- Выгружает последний апдейт в `.md`, чтобы его было удобно передать ИИ,
  и в `.html`, чтобы читать с форматированием на телефоне или компьютере.
  Markdown-файлы сохраняются в UTF-8 с BOM для корректного открытия на iPhone.
- В разделе «Апдейты» оставлены только три входа: новый апдейт, мои апдейты и
  назад. В «Моих апдейтах» есть динамика апдейтов и список файлов от поздних к
  ранним; у каждого апдейта в тексте есть ссылки редактирования, скачивания
  `.md` для ИИ и `.html` для чтения человеком. Кнопки в этом меню только две:
  «Динамика апдейтов» и «Назад».
- Отвечает сразу после сообщения пользователя, а между двумя сообщениями бота
  в одном чате выдерживает паузу 2 секунды.
- Отвечает на вопросы по Markdown-справочнику форума из `docs/forum-guide/`:
  теория форум-групп, классический Update и формат X-Competence.
- Принимает голосовые и audio, показывает транскрипт и использует его как ответ.
  Аудио не хранится на сервере и удаляется сразу после транскрибации.
- Режим дневника: свободные сообщения становятся дневниковыми записями, а бот
  даёт обратную связь по пользовательскому prompt.
- На следующее утро после форума сначала спрашивает личный план действий, затем
  здоровье форум-группы и пытается отправить отчёт указанному
  Telegram-пользователю, если он уже запускал бота.
- Раз в 3 месяца напоминает про личную стратегическую сессию в отеле.
- Держит основное меню коротким: «Апдейты», «Моя форум-группа», «Дневник»,
  «Личный кабинет», «Доп. информация». Справочные действия собраны в подменю
  «Доп. информация».
- Любая кнопка основного меню прерывает текущий сценарий или шаг и открывает
  выбранный раздел. Если нажать «Новый апдейт» до завершения настроек, бот
  сначала проведёт блок настроек.
- Логирует агрегаты пользователей и обращений; администратору сообщает о новых
  пользователях только ФИ и бизнес-клуб.

## Команды

| Команда | Что делает |
|---|---|
| `/start` | старт и онбординг |
| `/menu` | главное меню |
| `/forum`, `/update` | подготовка апдейта |
| `/nextforum` | изменить дату следующего форума |
| `/health` | health check форум-группы |
| `/guide` | справочник форума и вопросы по материалам |
| `/profile`, `/cabinet` | личный кабинет и редактирование профиля |
| `/about` | возможности бота |
| `/diary` | включить режим дневника или поменять prompt |
| `/diaryprompt` | поменять prompt дневника |
| `/stats` | статистика для админа |
| `/getid` | показать chat id |
| `/cancel` | остановить текущий сценарий |

## Runtime

- Python 3.9+
- `python-telegram-bot[job-queue]`
- OpenAI SDK для транскрибации и опциональной AI-сводки
- SQLite в `data/forum_update_helper.sqlite3`

Реальный `.env` не коммитится. Шаблон: `.env.example`.

## Сделать собственный бот

Инструкция для ИИ-агента: `CREATE_OWN_BOT.md`.

## Health report recipient

Для отправки отчёта пользователь указывает `@username` получателя. Бот сможет
отправить отчёт этому человеку только после того, как получатель сам запустил
бота хотя бы один раз. Если получатель ещё не найден, бот показывает отчёт
автору для ручной пересылки.

## Privacy

Кнопка «Удалить мои данные» удаляет локальные записи пользователя, состояние
сценариев, историю напоминаний, счётчики обращений и сохранённые файлы. Уже
доставленные сообщения в Telegram бот отозвать не может.
