# Методика с личной стратегией: X-Competence

Материал перенесён в Markdown для использования ботом и ИИ-агентами. Формат
собирает апдейт вокруг трёх сфер жизни и одного главного запроса к форуму.

## Смысл формата

Формат X-Competence помогает участнику подготовить не просто обзор месяца, а
связанный с личной стратегией апдейт:

- увидеть динамику в трёх сферах;
- сравнить текущий месяц с предыдущим;
- найти главную тему развития;
- сформулировать один запрос в зону контроля участника;
- прийти на форум с материалом, который можно обсуждать через личный опыт, а
  не через советы.

Базовое правило форума сохраняется: на встрече не дают советы, не анализируют
других и не устраивают мозговой штурм. Участники делятся личным опытом от
первого лица.

## Часть 1. Оценка трёх сфер

Оценить каждую сферу по шкале 1-10 и сразу назвать причины динамики:

| Сфера | Оценка этого месяца | Оценка предыдущего месяца | Что изменилось | Главный вклад | Причина роста / падения |
| --- | --- | --- | --- | --- | --- |
| Моё дело | | | | | |
| Моя семья / близкие | | | | | |
| Я | | | | | |

Важно: оценка 7 коварная, её не рекомендуется использовать. Она находится между
«хорошо» и «средне» и часто становится слишком нейтральным ответом.

Для каждой сферы это один объединённый вопрос:

- Какую оценку я ставлю этому месяцу?
- Какая была оценка предыдущего месяца?
- Что изменилось?
- Что дало наибольший вклад в эту оценку?
- Если оценка упала: что произошло?
- Если оценка выросла: за счёт чего?

| --- | --- | --- | --- | --- |

| Моя семья / близкие | | | | |

Вопросы:

- Что я планировал на прошедший период?
- Что получил по факту?
- Какое действие дало максимальный результат?
- Что не сработало и почему?

Для каждой сферы определить желаемый результат и факторы влияния.

| Сфера | Что будет «отлично» через месяц | Годовая цель | Что в моей власти | Что вне контроля | Что поддерживает / мешает |
| --- | --- | --- | --- | --- | --- |
| Моё дело | | | | | |
| Моя семья / близкие | | | | | |
| Я | | | | | |

Вопросы:

- Что будет означать для меня «отлично» через месяц?
- Какая годовая цель и как сегодняшний запрос с ней связан?
- Что в моей власти?
- Что вне моего контроля?
- Какие внешние факторы поддерживают?
- Какие внешние факторы мешают?

## Часть 4. Главный запрос

Из апдейта выбирается один вопрос, который сильнее всего влияет на жизнь и
развитие участника.

Хороший запрос:

- начинается с «Как мне ... ?»;
- не длиннее десяти слов;
- находится в зоне контроля участника;
- конкретный, не размытый;
- важный, но не сводится к операционной текучке;
- один, а не несколько запросов одновременно.

Пример направления:

> Как мне перейти на новый формат работы с ключевыми клиентами?

## Проработка запроса

### Суть и контекст

- Почему это важно?
- На какие сферы влияет?
- Кто ещё вовлечён?
- Как и когда начала развиваться ситуация?
- Что будет, если ничего не менять?

### Денежный эквивалент

- Какой ущерб или упущенная прибыль в год, если ничего не менять?
- Сколько я готов заплатить за лучшее решение?

### Идеальный конечный результат

- Как выглядит идеально разрешённая ситуация?
- Что изменится в поведении, системе, отношениях или бизнес-результате?

### Что уже пробовал

- Что я уже делал?
- Что сработало частично?
- Что не сработало?

### Варианты решения

Назвать минимум три варианта решения.

1. Первый вариант.
2. Второй вариант.
3. Третий вариант.

### Оптимальный вариант сейчас

- Если бы я не обсуждал это с группой, как бы я действовал?
- Какой вариант кажется наиболее рабочим прямо сейчас?

### Стоп-фактор

- Что останавливает от реализации оптимального решения?
- Какой страх, ограничение, риск или внешний фактор важно честно назвать?

### Помощь от группы

Формулировать просьбу к группе через опыт:

> Поделитесь опытом, как вы...

## Часть 5. Личный план действий

Заполняется по итогам подготовки и во время встречи.

- Суть запроса и идеальный результат после уточняющих вопросов группы.
- Ключевые инсайты и мысли, пока слушал других.
- Вопросы, на которые теперь буду искать ответ.
- Что вынес из запросов других участников.
- Благодарность себе и другим.

Действия в ближайшее время:

| Действие | Где / когда | С помощью чего | Ожидаемый результат | Срок |
| --- | --- | --- | --- | --- |
| | | | | |
| | | | | |

Для действия лучше использовать глагол совершенного вида: сделал, написал,
провёл, договорился, подготовил, отправил.
